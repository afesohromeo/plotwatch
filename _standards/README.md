## Quick Reference

- Architecture: **Clean Architecture + flutter_bloc + Freezed**
- State management: **BLoC** (never Riverpod, Provider, etc.)
- Models: **@freezed** always
- HTTP: **Dio** via `ApiProvider().dioExtSagePaie`
- Tables: **DataTable2 + AsyncDataTableSource**
- Routing: **GoRouter** with named routes
- **Localization: ⭐ NO hardcoded text anywhere** — use ARB files, all strings via `AppLocalizations` or `LocalizationService.localization`
- Layout: **ResponsiveScaffoldWrapper for all pages** ⭐
- Status enum: **GenericStatus** (initial / loading / filtering / success / failure)
- Flow tracking: **GenericFlowStep** (none / creatingItem / updatingItem / deletingItem)
