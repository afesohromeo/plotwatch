# Plotwatch

Plotwatch helps people fund construction they can't supervise in person. Site managers capture verified photo evidence (in-app camera, GPS inside the site boundary, server timestamp, hash check), funders approve the build stage by stage, and both sides share a ledger of every release and expense.

Built with Flutter and [Serverpod 4](https://serverpod.dev) for *Build Something Real: The Serverpod Hackathon* (2026). Work in progress: build and run instructions will be added here as the code lands.

Project documentation is in [`doc/`](doc/). Start with [`doc/00-project-context.md`](doc/00-project-context.md).
